## 底本与说明

- 底本为《连云港市志》纸质原书（上、中、下三册），数字化以 300dpi 原页扫描件为准。
- 正文经断行重排、双引擎 OCR 共识比对、逐卷人工通读校核；全书共完成 19 轮通读、数字矛盾逐条回源、连接号/坐标符号等专项。
- **照录原则**：凡原书自身的问题（数字矛盾、届次错位、用字不一、体例混杂等），一律保留原样并在校勘记录中留痕，绝不静默改写。全书共记录此类原书问题约 60 余处。
- 结构化表格均逐格回源核对，多数以横向求和、比值（破案率、平均工资等）自洽性交叉验证；原书自身总分不吻合者照录并注明。
