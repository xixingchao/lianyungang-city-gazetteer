# 第59卷全新重做执行任务单

本任务单从原件重新抽页后生成，不继承旧 OCR、旧重排文本或旧验收状态。

## 执行顺序

1. 运行全新 OCR：PaddleOCR 为主，RapidOCR 作为疑难对照。
2. 对每页做人工版面分流：正文、表格、音标/声韵调、同音字汇、方言词汇、页眉页脚。
3. 方言/音系页进入 dictionary mode，不并入普通正文清洗。
4. 每页生成新的人工校正文或结构化字典页。
5. 两轮逐字/逐项双审后，才能写通过结论。
